# NetworkWalks – Week 2 Cybersecurity Projects

## Overview
This repository contains my Week 2 cybersecurity project documentation completed as part of the NetworkWalks training program.

The projects focus on footprinting techniques and introductory network scanning using Kali Linux tools.

## Projects Completed

### PM1 – Footprinting
- WHOIS information gathering
- DNS lookup using dig
- DNS lookup using nslookup
- Host information using host
- Address resolution using getent
- Localhost connectivity verification using ping

### PM5 – Zenmap-Based Network Scanning
- Used Zenmap with Nmap 7.94SVN
- Performed a localhost scan using 127.0.0.1
- Reviewed host availability and TCP port states
- Examined scan output and topology visualization
- Documented scan findings and limitations
